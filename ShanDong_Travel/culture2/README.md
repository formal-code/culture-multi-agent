# Culture2

固定采集聊城官网文旅素材。运行 `main.py` 后输入一句自然语言需求。当前工作流会解析需求、按标题相关度发现并轮换浏览官网文章、从文章正文提取媒体、下载、审核并覆盖共享素材交付。

## PyCharm 首次设置

1. 用 PyCharm 打开 `culture2` 文件夹。
2. 在项目终端运行 `python -m venv .venv`，然后 `.venv\Scripts\python.exe -m pip install -r requirements.txt`。
3. 设置 Windows 用户环境变量 `DATA_OPENAI_API_KEY` 为百炼 API Key。不要把密钥填到 `config.py` 或提交到项目。
4. 重启 PyCharm，在项目解释器中选择 `.venv\Scripts\python.exe`。
5. 右键 `main.py`，选择“运行 main”，以后点击顶部绿色运行按钮即可。

模型默认 `qwen4-max`，API Host 默认沿用北京业务空间的非敏感主机名。可通过环境变量 `CULTURE_MODEL`、`DASHSCOPE_API_HOST` 或 `DASHSCOPE_BASE_URL` 覆盖。首次运行会调用模型解析需求，产生模型费用；当前每轮最多 501 次模型调用（含需求解析）、1800次网络请求、280个文章页面、500个候选素材和90分钟，媒体总下载量上限15GiB。审核模型请求可能产生费用；模型接口401/403/429/服务错误会停止调用，不自动重试。达到任何预算上限都会提前停止。

## 搜索和审核规则

- 搜索词只使用城市、区县、地点/文化对象和内容主题，自动清理模型误提取的成片形式、时长及受众要求。例如“聊城光岳楼视频，面向儿童，时长30s”只查询“光岳楼”“聊城 光岳楼”，不查询“视频”“儿童”“30s”；原始创作要求仍完整交给后续流程。明确要求某类素材时，素材类型过滤独立保留，不把类型词拼入搜索词。
- 只访问 `config.py` 中列出的7个聊城相关站点：聊城新闻网、市政府、市文旅局、东昌府区政府、大众网聊城、市自然资源和规划局、中国运河文化博物馆。不调用 Bing，也不根据用户输入拼造站外网址。
- 区分规则文件与媒体文件的访问结果：`robots.txt` 返回 403 时，记录“规则文件不可用”，继续检查页面中真实提供的公开地址；这不代表网站授权下载。正常读取到的明确禁止规则仍执行；媒体本身返回 401/403/429 时停止，不重试或更换身份。规则文件超时、5xx 或异常 HTML 仍会停止该域名的自动读取。
- 用户指定的例外在 `VIDEO_ROBOTS_WARNING_ONLY`：当前仅对 `api.lcxw.cn/upload/mp4/` 下页面真实提供的 MP4/WebM/MOV 视频地址，将正常读取到的 robots 禁止声明改为提示后尝试下载。这会忽略该范围的 robots 禁止意愿，不代表获得素材授权。文章、图片、其他路径和域名不适用；跳转后逐地址重新检查。媒体文件本身的拒绝响应、大小、时间和请求预算限制保持有效。配置改为空字典即可取消此例外。
- 具体景点/文化对象标题命中权重最高，主题其次，区县只作辅助；学校、会议、招标等新闻降权。每站最多连续浏览 5 页后轮换。
- 具体对象与宽泛主题分开处理。例如“聊城的风土人情”按民俗、婚俗、非遗、节庆、传统技艺等相关词发现文章，不要求文章原样出现“风土人情”；“聊城光岳楼的风土人情”仍要求来源涉及光岳楼。扩展词只用于检索和相关度判断，不作为文化事实写入交付。
- 发现文章后继续跟随栏目和搜索结果中的真实“下一页”、分页数字与 `rel=next` 链接，避免只停留在首页新闻。首先浏览 `INITIAL_PAGES` 页，队列未探索完时继续扩展到 `MAX_PAGES`；只打开已配置站点及页面真实提供的地址，不拼造翻页网址。
- 同一栏目或同一搜索词连续 `MAX_EMPTY_PAGINATION_PAGES` 页（默认 3 页）没有发现新的相关文章时，停止该分支翻页，继续其他栏目和网站；重复出现的置顶文章不算新线索。
- 首页缺少相关链接时，也可进入 `OFFICIAL_SITES` 中的 `entry_urls` 栏目入口，包含已确认的大众网文旅聊城栏目与运河博物馆社教活动栏目。聊城新闻网启用其首页真实提供的 GET 站内搜索表单，允许同站搜索服务 `lcadmin.lcxw.cn`；不推测其他搜索地址。站内搜索只使用真实 GET 表单及隐藏参数，按对象、区县加对象、城市加对象构造查询文字，不使用 Bing。主题搜索同时保留不带地名的查询与带地名的查询，每页最多12个，仍共用整轮页面、请求和模型额度。
- 评分会剔除 HTML 标题中的网站名、栏目名；下载前复核正文和图注是否涉及用户指定对象，减少审核无关博物馆、政务新闻等图片的模型费用。
- 首页只发现栏目和文章，不把首页缩略图当交付素材。文章媒体只从识别出的正文容器提取；图片和媒体必须有页面实际地址。支持大众网 `.news-con`、运河博物馆 `#article_content` 正文及对应标题结构；`/list/15.html` 等真实栏目不作为单篇文章处理。
- 创作要求中的“生成视频”“光岳楼视频”描述成片类型，默认同时搜集图片和视频；只有明确要求某类素材或排除另一类时才限制原始素材类型，不再直接采用模型对 `media_type` 的随机判断。需求里的非遗主题即使被模型漏填或错放到“聊城非遗”对象里也会修正；非遗检索词覆盖木版年画、葫芦雕刻、剪纸、戏曲等，扩展词只用于检索，不作为事实写入交付。模型温度设为0以减少重复请求的判断波动，但网络、站点内容和模型服务仍可能造成结果变化。
- 公开网页和 `robots.txt` 遇到连接/读取超时、临时连接错误或 HTTP 500/502/503/504 时，只在整轮额度内重读一次；二次失败仍跳过，规则未确认时不读取受保护资源。401/403/404/429 等网页拒绝不会因此重试；媒体下载和付费模型调用不自动重试。
- 图片通过视觉模型筛选并用一句话描述。视频不抽帧，只按来源文章标题/正文/关联文字概括，始终标记“画面未核实”。HLS `.m3u8` 播放清单不作为已下载视频交付。
- 多个指定对象按单项素材命中任意一个判断，例如东昌湖龙舟赛视频不必同时包含光岳楼。视频的“画面未核实”是固定说明，不是单独降为待核实的理由；文章主题不清、来源引文缺失或无法定位、会议政务等仍按规则处理，不自动放行待核实素材。播放器 `src` 中的 PNG/JPG 等图片和明确标注为图片的 source 不计为视频候选。
- 图片默认拒绝博物馆等展馆内的陈列物品图，包括展柜文物、藏品、标本、静态非遗展品、展板、蜡像/人偶、复原陈列及以这些陈列为主体的展厅全景。只有用户明确要求这类图片并由需求解析记录原话证据时才解除默认排除，仍需通过质量和需求审核。仅提到博物馆、历史文化或非遗不算例外；博物馆建筑外观、真实技艺制作和现场民俗表演按普通图片规则审核。默认情况下必须明确确认不属于陈列图才能通过；拒绝的文件不保留。
- 不设总素材数、图片数或视频数的最低要求。搜索会继续整个发现队列，直到候选队列耗尽或达到页面、候选、网络、模型、下载量、时间上限；通过素材会全部交付。候选上限500包含下载失败、review和reject，不代表保证尝试到500或交付500份。
- 每次搜索结束都完整替换共享素材包；无论本轮通过多少素材，上一轮的 `assets/`、研究 JSON 和来源记录都会被本轮结果替换。本轮没有合格素材时发布空素材目录和空清单，不保留上轮素材。模型超时或接口异常停止时，只交付本轮停止前通过审核的素材。每轮只从网站新发现的内容中筛选，不自动复用旧素材。
- 模型连接等待上限为 8 秒、回复数据的读取等待上限为 45 秒，可在 `config.py` 调整。该等待与整轮 90 分钟时限分别计算。连接超时、读取超时和连接中断分别记录；失败不自动重试，以免重复计费。
- `review` 和 `reject` 状态的图片/视频不保留文件，只在采集报告中记录原因，不计入通过数量；不生成 `review/` 文件夹，发布时清理旧版本留下的该文件夹。

## 扩大搜索范围

在 `config.py` 中调整 `INITIAL_PAGES`（首阶段页数）、`MAX_PAGES`、`MAX_CANDIDATES`、`MAX_MODEL_CALLS`、`MAX_REQUESTS`、`MAX_DOWNLOAD_BYTES` 和 `MAX_SECONDS`。增加官网时，填写唯一 `id`、名称、首页、允许的文章主机名与已确认栏目入口；不要用媒体CDN代替文章网站。纯JavaScript分页、播放器或特殊正文仍可能需要适配。增加预算不能保证站点提供足够的可下载媒体。

## 交付

`data/聊城/assets/` 放素材；`research.json` 给素材 Agent 使用；`fact.json` 放从来源正文、标题或图注摘录的陈述并标记未独立核实，`evidence_type` 和 `evidence_quote` 标明位置与原文；`sources.json` 保存来源文章、正文与媒体关联；`collection_report.json` 保留本轮访问与失败原因。主题需求也按扩展主题词提取原文，仅有视频标题时记录标题陈述，不从视觉描述或常识补写文化事实。同源同句只存一条，通过 `asset_ids` 与素材的 `fact_refs` 互相关联。事实提取只发生在素材筛选之后，不参与搜索、素材审核和通过数量统计；没有事实的合格素材照常交付，标记 `fact_status=no_source_statement`，不降为review。`research.json` 中的视频描述注明仅基于来源文字，未核实视频画面。

## 当前边界

本版本通过公开 HTML 找栏目、文章及页面中真实存在的图片/视频地址；不破解验证码、登录墙、签名或访问限制。站点结构不同可能造成正文无法识别，详情记录在 `collection_report.json`。动态播放器和需 JavaScript 解密的流不保证找到直链。依赖文章标题和正文的分数先筛掉弱相关入口，实际正文标题仍会复核；不设最低交付数量；500 为候选尝试上限，实际数量取决于发现结果和预算。
